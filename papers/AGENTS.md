# Paper Workspace Instructions

These instructions apply to all work on the English implementation and
evaluation paper in this directory.

Before editing or resuming paper work, read:

1. `PAPER_WRITING_RULES.md`
2. `implementation_evaluation_paper_plan.md`
3. The latest entry in `PAPER_WRITING_SESSION_LOG.md`

The supervisor-proposed six-section structure in the plan is controlling.
Keep the PFE and master theses as source material, not as manuscript text to
copy. Verify project claims against current machine-readable evidence before
publication. Preserve separate controlled, clean, partial, no-signal,
source-denominator, constrained upper-bound, report-only, and limitation
lanes. Record each paper-writing session in the session log and update the
plan checkpoint.
